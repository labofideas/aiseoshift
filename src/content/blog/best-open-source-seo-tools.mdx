The best open source SEO tools in 2026 are SerpBear for rank tracking, SEOnaut and SiteOne Crawler for site audits, Unlighthouse and Google Lighthouse for performance and Core Web Vitals, Matomo, Plausible or Umami for analytics, advertools for Python-based SEO analysis, and The SEO Framework or Yoast SEO for WordPress. Every tool on this list is genuinely open source and was actively maintained as of October 2026.

One honest note first: there is no open source equivalent to Semrush or Ahrefs. Those platforms run on enormous proprietary databases of backlinks, keywords and search volumes that no open source project maintains. What open source does well is the work you can run on your own site: tracking, crawling, auditing, measuring and fixing. For many teams, that covers most of the day-to-day.

## Why use open source SEO tools

- **No subscription.** You pay for hosting, if anything.
- **You own the data.** Rankings, crawl results and analytics stay on your server.
- **Privacy.** Self-hosted analytics avoids sending visitor data to third parties.
- **Automation.** Command-line tools and libraries slot into scripts, CI pipelines and AI workflows.
- **No seat limits.** Add your whole team or every client.

The trade-off is setup time and maintenance. Pick tools with active development, because SEO tools that stop updating break as Google and browsers change.

## Rank tracking

### 1. SerpBear

SerpBear is the most polished open source rank tracker: a clean dashboard that tracks your keyword positions in Google over time, with competitor tracking and email reports. It is MIT licensed, built with Next.js and runs in Docker.

To fetch rankings it connects to a search results scraping service such as ScrapingRobot, SerpApi or ScrapingAnt. Some have free tiers big enough for a small keyword list; larger lists cost money per request.

**Strength:** easy to use and actively maintained.
**Weakness:** depends on an outside scraping service, so cost and reliability are partly out of your hands.

For tracking visibility in AI answers rather than Google rankings, open source options are still thin. See our guide to [AI visibility tools](/blog/best-ai-visibility-tools-2026/).

## Site crawling and audits

### 2. SEOnaut

SEOnaut is a self-hosted site crawler and auditor written in Go. Point it at a site and it reports issues such as broken links, redirect chains, missing titles and descriptions, duplicate content and indexing problems, organized by project in a web dashboard. It needs no external API.

**Strength:** a self-contained, web-based audit tool you can share with a team.
**Weakness:** a smaller community than commercial crawlers.

### 3. SiteOne Crawler

SiteOne Crawler is a fast, single-binary crawler for Windows, macOS and Linux that checks SEO, security headers, accessibility and performance in one pass and produces a shareable HTML report. It can also generate sitemaps and offline copies of a site. It is written in Rust, MIT licensed and very actively developed.

**Strength:** no dependencies, broad audit coverage, frequent updates.
**Weakness:** command-line first, which suits technical users more than beginners.

### 4. Unlighthouse

Unlighthouse runs Google Lighthouse against every page of your site, not just one, and shows the results in a live dashboard: performance, Core Web Vitals, accessibility, best practices and SEO scores per page. Run it with a single npx command or Docker.

**Strength:** the easiest way to find your slowest and weakest pages across a whole site.
**Weakness:** heavy on large sites, since it runs a headless browser for each page.

### 5. Google Lighthouse

Lighthouse is Google's own open source auditing tool, built into Chrome DevTools and available as a command-line tool and Node package. It scores a page on performance, accessibility, best practices and SEO, with specific fixes.

**Strength:** the reference standard, maintained by Google.
**Weakness:** one page at a time by default. Pair it with Unlighthouse for full sites.

See our guide to [Core Web Vitals and AI search](/blog/core-web-vitals-ai-search-2026/) for what to do with the results.

### 6. python-seo-analyzer

A lightweight Python tool that crawls a site or sitemap and reports common on-page issues, with JSON output that is easy to feed into scripts or CI checks. Install with pip.

**Strength:** quick, scriptable checks.
**Weakness:** much shallower than a full crawler.

## SEO data analysis

### 7. advertools

advertools is a Python library for technical SEO and data work: crawling sites, parsing robots.txt and sitemaps, analyzing server logs, working with SERP data and building keyword lists. It is popular with technical SEOs who work in notebooks.

**Strength:** enormous flexibility for analysis and automation.
**Weakness:** code only, no interface.

## Analytics

Rankings and audits tell you what search engines see. Analytics tells you what visitors do. These three are the leading open source alternatives to Google Analytics. Pair any of them with Google Search Console, which is free and remains the only source of Google's own search query data.

### 8. Matomo

Matomo is the most complete open source analytics platform, with goals, funnels, heatmaps and A/B testing, and it can import data and run on your own server. Licensed GPL-3.0.

**Strength:** closest to Google Analytics in depth.
**Weakness:** heavier to host and scale than the lighter options.

### 9. Plausible Community Edition

Plausible is privacy-first, cookie-free analytics with a simple one-page dashboard, and its Community Edition can be self-hosted with Docker. Licensed AGPL-3.0.

**Strength:** lightweight and easy to read.
**Weakness:** the self-hosted edition has fewer features than Plausible's paid cloud version.

### 10. Umami

Umami is simple, fast analytics under the permissive MIT license, deployable with Docker or Node and a Postgres or MySQL database. It is one of the most popular open source analytics projects on GitHub.

**Strength:** the simplest to deploy and the most permissive license.
**Weakness:** fewer advanced features than Matomo.

## WordPress SEO plugins

All four are GPL licensed, like WordPress itself. They handle titles, meta descriptions, sitemaps, canonical tags and structured data. Pick one; never run two at once.

### 11. Yoast SEO

The most widely used WordPress SEO plugin, with mature sitemap, schema and readability tools. The free version is fully usable, with upgrade prompts for Premium.

### 12. The SEO Framework

Lightweight and fast, with sensible defaults, no ads and no upsell nagging in the dashboard. A favorite of developers and agencies.

### 13. Rank Math

The richest free feature set of the WordPress plugins, including schema types, redirections and 404 monitoring. Some features connect to a Rank Math account, which the plugin discloses.

### 14. Slim SEO

Deliberately minimal: it handles the essentials automatically with almost no settings. Best for people who want SEO basics done without configuring anything.

## Bonus: open source MCP servers for SEO

If you work with AI assistants, several small open source MCP servers connect Claude and other assistants to Google Search Console, so you can ask questions about your search data in plain language. None has large adoption yet, so review the code before granting access to a real property. Our list of the [best SEO MCP servers](/blog/best-seo-mcp-servers-github/) covers the options in detail.

## Projects to skip

These still appear in older "open source SEO" lists, but they are no longer maintained as of October 2026:

- **Serposcope:** the Java rank tracker's GitHub repository is archived, with no updates since January 2024.
- **Greenflare:** the Python desktop crawler has had no code changes since mid-2023.
- **SEO Panel:** the PHP all-in-one suite has had no code changes since 2023.

Unmaintained tools break as search engines change and may carry unpatched security issues. Use the active alternatives above.

## A free open source SEO stack

For a small business or a single site:

1. **Google Search Console** for search queries and indexing (free, not open source, essential).
2. **Umami or Plausible** for privacy-friendly analytics.
3. **SiteOne Crawler or SEOnaut** for a monthly technical audit.
4. **Unlighthouse** once a quarter for performance across the site.
5. **SerpBear** with a free-tier scraping API for your top 50 keywords.
6. **The SEO Framework or Yoast** if you run WordPress.

For agencies and technical teams, add **advertools** for analysis and automation, and **Matomo** if clients need deeper analytics.

## What open source cannot replace

Be clear about the gaps before you cancel paid tools:

- **Backlink data.** No open source project crawls the web for links at scale.
- **Keyword volumes and difficulty.** These come from proprietary datasets.
- **Competitor traffic estimates.** Same problem.
- **AI search visibility.** Tracking how ChatGPT, Gemini and Perplexity mention your brand is mostly a paid category today.

Many teams run an open source stack for daily work and keep one paid tool for backlinks and keyword research. That is usually the best value. See our [best AI SEO tools](/blog/best-ai-seo-tools/) for paid options.

## The bottom line

Open source will not give you one platform that does everything, but it gives you excellent, free tools for rank tracking, auditing, analytics and on-site SEO, with your data on your own server. Stick to projects that are actively maintained, start with the stack above, and add a paid tool only for the data open source cannot provide.
