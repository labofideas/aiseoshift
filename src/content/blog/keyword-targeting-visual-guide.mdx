Keyword targeting means deciding that one page owns one primary keyword and its search intent, then aligning the whole page, title, headings, and content, to that query. Do it right and each page has a clear job. Do it wrong and you point several pages at the same keyword, so they compete with each other and none of them wins.

One page, one primary query. That is the rule the rest of this follows.

## Step one: match the keyword to intent

A keyword is not just words, it is a request. Before you target one, run it and read the top results. If they are all comparison articles, the intent is commercial research, and a hard product page will not win there no matter how optimized it is.

Match the page type to the intent behind the query. Informational queries want explainers, commercial ones want comparisons, transactional ones want product or service pages. Targeting the wrong intent is the most common reason a well-optimized page still fails. The [search intent glossary entry](/glossary/search-intent/) breaks down the types.

## Step two: one primary keyword per page

Give each page a single primary keyword and a small set of close variations. Do not aim two pages at the same query.

When two of your pages target one keyword, Google does not know which to rank, so it often ranks neither well and splits your signals between them. That is keyword cannibalization, and the fix is to consolidate the pages or clearly differentiate their targets. For where each keyword then goes on the page, see [where to include keywords on a blog post](/blog/where-to-put-keywords-blog-post/).

Once the target is set, make the whole page reflect it. The title and H1 carry the keyword, the first paragraph answers the query directly, at least one subheading reinforces it, and the body covers the topic with genuine depth and natural variations. The point is not repetition, it is coherence: every part of the page pointing at the same query so there is no ambiguity about what it is for. The rest of the on-page rules are in [on-page SEO](/seo/on-page-seo/).

Target with intent, one page per query, and align the page to it. That is keyword targeting in one line.

## FAQs

### What does keyword targeting mean in SEO?

Keyword targeting means assigning one primary keyword and its search intent to a single page, then aligning the whole page (title, headings, and content) to that query. It ensures each page has a clear job and does not compete with your other pages for the same term.

### What is keyword cannibalization?

Keyword cannibalization is when two or more of your pages target the same keyword, so search engines cannot tell which to rank and often rank neither well. The fix is to consolidate the competing pages into one or clearly differentiate their target keywords and intent.

### How do I match a keyword to the right page?

Run the keyword and read the top results to see the intent. If they are explainers, the intent is informational; if comparisons, commercial; if product pages, transactional. Build the page type that matches, because targeting the wrong intent is the most common reason an optimized page still fails to rank.
