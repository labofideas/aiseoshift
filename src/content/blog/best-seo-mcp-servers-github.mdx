When we first published this guide in May 2026, every SEO MCP server worth using was a community project on GitHub. Four months later, the landscape has flipped: **Ahrefs, SE Ranking, and DataForSEO now ship official MCP servers**, and the smart setup in late 2026 combines one official vendor MCP with two or three focused community servers.

This is the fully updated list. What each server connects to, what it actually exposes, how hard setup is, and where each one falls short. We use several of these daily to run this site.

If you're new to the concept: an MCP (Model Context Protocol) server is a bridge that lets an AI assistant like Claude query a live data source (your Search Console, your rank tracker, your crawler) instead of working from pasted CSVs. Connect one and "check which pages lost impressions this week" becomes a single prompt instead of an export-filter-paste ritual. For a deeper look at how AI tools interact with your content, see our guide on [LLM crawler optimization](/blog/llm-crawler-optimization/).

## The short version

- **Have a paid Ahrefs plan?** Install the official Ahrefs MCP first. It's included with every paid tier and takes one command.
- **On SE Ranking?** Their MCP adds something nobody else has: AI search visibility data (ChatGPT, Gemini, Perplexity, AI Overviews, AI Mode) alongside classic rankings.
- **No paid tools?** Start with `mcp-gsc` for Search Console plus a PageSpeed server. Both are free.
- **Building agent pipelines?** DataForSEO's official server is the pay-per-use workhorse.

## Official vendor MCP servers

### 1. Ahrefs MCP (official): best if you already pay for Ahrefs

- **Repo:** [github.com/ahrefs/ahrefs-mcp-server](https://github.com/ahrefs/ahrefs-mcp-server)
- **Type:** Hosted remote MCP. Nothing to install or run locally.

The biggest MCP news since our last update. Ahrefs open-sourced its server and hosts it at `api.ahrefs.com/mcp/mcp`, and it's **included with every paid plan, Lite through Enterprise, with no separate API subscription**. That pricing decision alone makes it the default recommendation for most SEOs.

Coverage is wide: Site Explorer, Keywords Explorer, Rank Tracker, GSC Insights, Brand Radar, Site Audit, Web Analytics, Content Explorer, AI Content Helper, and even Google Business Profile monitoring via GBP Monitor.

Setup in Claude Code is one line (from the [official docs](https://docs.ahrefs.com/en/mcp/docs/claude-code)):

```bash
claude mcp add ahrefs https://api.ahrefs.com/mcp/mcp -t http
```

**Best for:** competitor comparisons, backlink prospecting, diagnosing organic performance drops without leaving your terminal.

**Honest limitation:** it reads your Ahrefs data; it doesn't replace Ahrefs' UI for deep manual digging, and heavy agentic use still consumes your plan's data rows.

### 2. SE Ranking MCP: the only one with AI search visibility data

- **Docs:** [seranking.com/blog/claude-code-for-seo](https://seranking.com/blog/claude-code-for-seo/)
- **Type:** Official, connects via Claude Connectors or MCP config

SE Ranking's MCP combines classic SEO data (rankings, backlinks, keyword research, competitive analysis) with the thing no other server on this list offers: **visibility data across ChatGPT, Gemini, Perplexity, AI Overviews, and AI Mode**. If your reporting includes "are we cited in AI answers," this is currently the only MCP route to that data.

Setup takes about 10 minutes and requires an SE Ranking plan with the API add-on, or a standalone API subscription. SE Ranking documents three workflows: writer-ready content briefs (they claim 3–4 hours of research compressed to under 10 minutes), competitive AI-visibility reports across LLM engines, and scripted backlink analysis with client-ready deck output.

**Best for:** agencies reporting on AI search visibility alongside rankings.

**Honest limitation:** read-only (queries only, no account modifications), and the API add-on is an extra cost on top of your plan.

### 3. DataForSEO MCP (official): pay-per-use data for pipelines

- **Repo:** [github.com/dataforseo/mcp-server-typescript](https://github.com/dataforseo/mcp-server-typescript)

DataForSEO's official TypeScript server exposes their SERP, keyword research, backlink, and on-page APIs. There's no monthly seat. You pay per API call, which makes it the natural choice for **scheduled agent jobs** where a subscription tool would be wasted on intermittent use.

**Best for:** programmatic SERP checks, bulk keyword data inside agent workflows.

**Honest limitation:** costs scale with usage, and an over-eager agent loop can burn credits fast. Set spending alerts before you let an agent run unattended.

## Community GitHub servers

The projects below are community-built. Quality is generally good, but check the repo's recent commits before trusting one in a client workflow.

### 4. mcp-gsc: free Search Console access (install this first)

- **Repo:** [github.com/AminForou/mcp-gsc](https://github.com/AminForou/mcp-gsc)

Connects Claude to Google Search Console: performance queries, page-level data, sitemap and indexing checks. Since GSC's own interface still caps and samples exports, asking Claude to pull and segment the data directly is genuinely faster. This is the server we use most. Our monthly traffic audits for this site run through it.

**Best for:** everyone. It's free and GSC is the ground truth.

**Honest limitation:** Google API quota limits apply, and setup requires creating a Google Cloud service account, which makes it the fiddliest install on this list.

### 5. claude-seo: the broad toolkit

- **Repo:** [github.com/AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo)

The most complete general-purpose SEO toolkit for Claude, with 25 sub-skills spanning audits, on-page analysis, and content checks.

**Best for:** one-install breadth when you don't want five separate servers.

**Honest limitation:** breadth over depth. Vendor MCPs beat it wherever they overlap.

### 6. Bing Webmaster MCP: the other search engine's ground truth (new)

- **Repo:** [github.com/isiahw1/mcp-server-bing-webmaster](https://github.com/isiahw1/mcp-server-bing-webmaster)

40+ tools over the Bing Webmaster API: traffic analysis, crawl diagnostics, URL submission, sitemap management, keyword research, link analysis. With Copilot answering from Bing's index, Bing data stopped being optional. If you optimize for Copilot visibility, this is where you verify indexing.

**Best for:** Copilot-era Bing coverage next to your GSC data.

**Honest limitation:** community-maintained, and the Bing API itself is less consistent than Google's.

### 7. mcp-integrations bundle: Bing + WordPress + Clarity + Cloudflare (new)

- **Repo:** [github.com/urdigitalau/mcp-integrations](https://github.com/urdigitalau/mcp-integrations)

One repo bundling four servers: Bing Webmaster Tools, WordPress, Microsoft Clarity, and Cloudflare Analytics. The WordPress server is the sleeper. An agent that reads GSC, then drafts the fix directly into WordPress, closes the loop most stacks leave open.

**Best for:** WordPress sites wanting analyze-and-act in one config.

**Honest limitation:** jack-of-all-trades depth; each bundled server is thinner than its dedicated equivalent.

### 8. pagespeed-mcp-server: Core Web Vitals on tap

- **Repo:** [github.com/sofianbettayeb/pagespeed-mcp-server](https://github.com/sofianbettayeb/pagespeed-mcp-server)

Wraps the PageSpeed Insights API for performance and technical checks. (Alternative: [ruslanlap/pagespeed-insights-mcp](https://github.com/ruslanlap/pagespeed-insights-mcp), a similar wrapper tuned for Claude.)

**Best for:** batch CWV checks across URL lists.

**Honest limitation:** it's the PSI API with an MCP face. Same rate limits, same lab-data caveats.

### 9. seo-research-mcp: free backlink and keyword lookups

- **Repo:** [github.com/egebese/seo-research-mcp](https://github.com/egebese/seo-research-mcp)

Free Ahrefs-powered backlink and keyword data without an Ahrefs subscription.

**Best for:** quick lookups on a zero budget.

**Honest limitation:** free data sources are limited and can break. Don't build client reporting on it.

### 10. screaming-frog-mcp: talk to your crawls

- **Repo:** [github.com/bzsasson/screaming-frog-mcp](https://github.com/bzsasson/screaming-frog-mcp)

Drives Screaming Frog crawls and lets Claude interrogate the results. "List every page with a missing canonical over 3 clicks deep" becomes a prompt instead of a filter chain.

**Best for:** technical SEOs who live in Screaming Frog.

**Honest limitation:** requires a licensed Screaming Frog install running locally.

### 11. advanced-seo-mcp: schema validation

- **Repo:** [github.com/halilertekin/advanced-seo-mcp](https://github.com/halilertekin/advanced-seo-mcp)

Focused on structured data: validate schema, spot markup gaps. Pairs well with our [schema-for-AI-search series](/blog/event-schema-for-ai-search/).

**Best for:** sites where schema drives AI citations.

**Honest limitation:** narrow by design.

### 12. seo-mcp-server: on-page scoring

- **Repo:** [github.com/Docker-Hunterpedia/seo-mcp-server](https://github.com/Docker-Hunterpedia/seo-mcp-server)

On-page analysis and scoring for individual URLs.

### 13. seo-insights-mcp-server: backlinks, keywords, traffic

- **Repo:** [github.com/mrgoonie/seo-insights-mcp-server](https://github.com/mrgoonie/seo-insights-mcp-server)

General backlink, keyword, and traffic analysis. A lighter free alternative when the vendor MCPs are out of budget.

### 14. Your own GSC + custom server

The dark-horse option: MCP servers are small programs. If you have a developer (or Claude Code itself), a custom server over your own stack (GSC + GA4 + your CRM) often beats any off-the-shelf pick. That's how our [AI SEO dashboard](/blog/ai-seo-dashboard-setup/) works.

## Which should you install first?

**The minimum stack (free):** `mcp-gsc` + a PageSpeed server. Ground truth plus performance, $0.

**The professional stack:** official Ahrefs MCP (or SE Ranking if AI visibility reporting matters) + `mcp-gsc` + `screaming-frog-mcp`. This covers off-site, ground truth, and technical. It's the setup we'd rebuild first if our config was wiped tomorrow.

**The pipeline stack:** DataForSEO + `mcp-gsc` + the WordPress server from `mcp-integrations`, feeding a scheduled Claude Code job. See our guide to [SEO AI agents](/blog/seo-ai-agents/) for what that unlocks.

Don't install all fourteen. Every connected server adds tool definitions to your assistant's context, and past five or six servers, tool selection gets noticeably worse. Pick per job.
