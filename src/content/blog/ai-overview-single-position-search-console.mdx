Someone shares a screenshot of Search Console's help docs and it goes semi-viral because nobody knew it. That is what happened this week with a fact that has actually been sitting in Google's documentation since 2025: an AI Overview counts as one position, and every link inside it shares that position, no matter where in the block it sits.

It is real. It is also not new. And that combination is exactly why it is worth writing down properly.

## What the documentation actually says

Search Console's help page on impressions, position, and clicks lays out three rules for AI Overviews specifically. Clicking a link to an external page in the AI Overview counts as a click. Standard impression rules apply. And then the one that catches people off guard: "An AI Overview occupies a single position in search results, and all links in the AI Overview are assigned that same position."

Read that twice. It does not say your link's position within the AI Overview. It says the AI Overview's position, full stop, and every link inside inherits it.

Google's John Mueller has said the same thing in his own words, outside the docs: "Basically an AIO counts as a block, so it's all one position. It can be first position, if the block is shown first, but I don't know if AIO is always shown first." That last clause matters too. The block's position can move around the page from query to query. What stays fixed is that whatever number the block lands on, every link inside it gets stamped with that same number.

## Why "average position" stops meaning what you think

Average position has always been a proxy for "how prominent was my link, on average." For classic blue links that proxy holds up reasonably well. Position 2 usually beats position 8.

Inside an AI Overview, the proxy breaks. Your link might be the very first citation a user sees, the kind of placement that would earn genuine trust and clicks. Or it might be the fourth of four sources, tucked behind a "show more" tap almost nobody presses. Search Console cannot tell you which. Both situations report identically.

That means a dashboard showing "average position 3.2 in AI Overviews" is telling you something real about where the block itself tends to sit on the page. It is telling you nothing about how prominently your specific link is cited relative to the other sources next to it.

## A related quirk worth knowing at the same time

There is a second, closely related clarification from Mueller worth pairing with this one. When the same URL appears both inside an AI Overview and in the regular organic results for the same query, Search Console does not double-count it as two impressions. It counts once. If you have been eyeballing impression totals expecting AI Overview visibility to stack cleanly on top of your organic numbers, it does not always work that way for a URL doing double duty on both surfaces.

Both quirks point at the same underlying truth. Search Console's AI Overview reporting borrows the vocabulary of the classic Performance report, position, impressions, clicks, but the surface underneath those words behaves differently enough that the old intuitions do not transfer cleanly.

## What to actually do with this

Stop treating AI Overview average position as a citation-prominence metric. It is not one. Use it only to understand roughly where the AI Overview block tends to appear on the page for your queries, not where your link sits within it.

Lean on the dimensions Search Console actually gives you cleanly instead: which pages get cited, which queries trigger those citations, and how impressions and clicks trend over time for those pages. That page-level and query-level data is real and actionable. The [generative AI performance report](/blog/google-search-console-ai-performance-report/) is the place to read it, and the broader [tracking playbook for AI Overview citations](/blog/google-search-console-ai-visibility/) covers how to build a routine around it. If you are also watching the click side of this data, [AI clicks in Search Console](/blog/ai-clicks-search-console/) is the companion piece.

One number that looks precise is not the same thing as one number that is meaningful. The AI Overview position figure is the first one, dressed up to look like the second.
