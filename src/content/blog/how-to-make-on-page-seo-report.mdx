An on-page SEO report evaluates a single page against a fixed checklist, title and meta, headings, keyword and intent match, content depth, internal links, images, and structured data, then flags what is missing and ranks the fixes by impact. Build it by checking each element, marking it pass or fix, and ending with a short, prioritized action list. A good report is not a wall of data. It is a page, a checklist, and a plan.

Here is what goes in each part.

## The seven checks

Go element by element for the page you are auditing.

**Title and meta.** Is the title under about 60 characters, unique, and does it carry the target keyword near the front? Does the meta description sell the click and stay under about 160 characters?

**Headings.** Exactly one H1 that carries the topic, then a logical H2 and H3 structure that reads as the questions people ask.

**Keyword and intent.** One clear primary keyword, and a page type that matches the intent behind it. Run the query and confirm the top results are the same format you built.

**Content depth.** Is the direct answer near the top? Does the page cover the topic thoroughly, with original detail rather than generic filler? Free tools like [meta checker](/tools/meta-checker/), [heading checker](/tools/heading-checker/), and [keyword density](/tools/keyword-density/) speed up several of these checks.

**Internal links.** Links out to related pages and links in from relevant ones, with descriptive anchor text.

**Images.** Compressed, correctly sized, with descriptive alt text on the meaningful ones.

**Structured data.** Appropriate schema (Article, FAQPage) present and valid.

A report that only lists problems is half a report. End it with a prioritized action list. Sort the fixes by impact versus effort: do the high-impact, low-effort ones first, schedule the big ones, batch the small easy ones, and skip anything low-impact and hard. That turns the audit into a plan someone can actually work through.

Keep the format simple: one page, the seven checks marked pass or fix, and the ranked action list at the bottom. The measurement side of tracking whether the fixes worked is in [measuring SEO](/seo/measuring-seo/).

## FAQs

### What should an on-page SEO report include?

Seven checks for the page: title and meta, headings, keyword and intent match, content depth, internal links, images and alt text, and structured data. Each is marked pass or fix, and the report ends with a prioritized list of the fixes to make, ranked by impact versus effort.

### How do I create an on-page SEO report for free?

Audit the page element by element against the seven checks using free tools. Google Search Console shows how the page performs, and on-page checkers for meta tags, headings, and keyword usage speed up the review. Record each issue and end with a short, prioritized action list.

### What is the difference between an on-page SEO report and a full site audit?

An on-page report evaluates the elements of a single page, while a full site audit covers the whole domain, including technical health, site architecture, indexing, and site-wide quality signals. The on-page report is one input into the larger audit.
