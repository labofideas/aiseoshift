OpenAI's 2026 pricing spans a wide GPT-5 lineup, the Codex coding agent, and ChatGPT subscription plans. This guide pulls the current numbers into one place.

Everything here is accurate as of June 10, 2026. Confirm against the official pages before budgeting, since rates change often.

## OpenAI API pricing by model

Rates are per million tokens, input/output.

| Model | Input ($/M) | Output ($/M) | Best for |
|---|---|---|---|
| GPT-5.5 | $5 | $30 | Token-efficient flagship; 1M context |
| GPT-5.5-pro | $30 | $180 | Maximum capability, premium price |
| GPT-5.4 | $2.50 | $15 | Recommended production workhorse |
| GPT-5.4 Mini | $0.75 | $4.50 | Budget mid-tier |
| GPT-5.4 Nano | $0.20 | $1.25 | Cheapest current tier |
| GPT-5.3-Codex | $1.75 | $14 | Default model inside Codex |

**GPT-5.5** is the flagship, notable for reaching strong results with fewer tokens, which can offset its higher per-token rate. **GPT-5.4** is the practical workhorse for production at $2.50/$15, with Mini and Nano variants for cheaper, lighter jobs. For coding, **GPT-5.3-Codex** is the default inside the Codex agent.

Legacy budget models remain available, including GPT-4.1 nano around $0.10/$0.40 for simple, high-volume tasks.

## Codex: OpenAI's coding agent

Codex is OpenAI's cloud-based autonomous coding agent powered by the GPT-5 family. It runs multi-step tasks in isolated sandboxes and works in parallel across projects, making it the direct competitor to Anthropic's Claude Code.

Since April 2, 2026, Codex bills with token-based credits rather than per message. Credits are consumed as input plus cached input plus output, each at the model's rate. Cached input (repeated project context) costs roughly 10% of the input rate, which is the most important cost lever in any agentic workflow.

## ChatGPT and Codex subscription plans

| Plan | Price | Notes |
|---|---|---|
| ChatGPT Plus | $20/mo | Flagship access for individuals |
| ChatGPT Pro | $200/mo | Highest limits; heavy users |
| Codex Plus | $20/mo | 10-60 cloud tasks / 5-hr window |
| Codex Pro (5x) | $100/mo | ~5x capacity; active developers |
| ChatGPT Team | $25-$30/seat | GPT-5.5 access, shared workspace, admin |
| Enterprise | Custom | Governance, security, scale |

In practice, Codex runs roughly $100-$200 per developer per month, with wide variance based on model choice, parallel instances, and automation.

## Which OpenAI option should you pick?

For everyday assistant use, ChatGPT Plus is enough. For full-time coding with the Codex agent, Codex Pro almost always beats per-token billing. On the API, default to GPT-5.4 for production, drop to Mini or Nano for routine jobs, and reserve GPT-5.5 or 5.5-pro for the work that genuinely needs the extra capability. Cache aggressively; it is the single biggest saving.
