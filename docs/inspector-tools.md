# Schema and website technology tools

Routes: `/tools/schema-markup-validator/` and `/tools/website-technology-checker/`.
Both appear in the tools directory and footer. The shared `InspectorTool.astro`
layout follows the site's existing type, color and light/dark theme tokens.

## Coverage

Schema: JSON-LD syntax, common structure, vocabulary names, inherited property
usage, and selected primitive value warnings. Handles multiple blocks, arrays,
nested nodes and @graph. Microdata/RDFa are counted but not validated. Complex,
mixed and external JSON-LD contexts are not expanded. This is not a full JSON-LD
processor, Google eligibility test, or ranking score. Warnings about Schema.org's
flexible domains/ranges are advisory. Each report includes its coverage notes.

Technology: deterministic rules over generator tags, actual script/stylesheet
URLs, selected DOM attributes/elements and an allowlist of response headers.
Matches include evidence and confidence. No paid API or LLM is needed. WordPress
plugin directories are deduplicated; their presence is evidence of public assets,
not a complete or guaranteed active-plugin inventory. Up to four discovered
conventional theme stylesheets are queried for declared name, author, version,
and parent theme. Renamed wp-content directories, bundled assets and JS-only
signals may be missed. Pasted HTML never triggers stylesheet requests.

## Fetching and limits

`fetch-page` preserves its HTML response contract for all existing tools and adds
selected headers. `theme-info` only accepts conventional discovered stylesheet
paths. Both use `public-fetch.ts`: HTTP(S), public domains, no credentials/custom
ports/IP literals, A/AAAA checks through Cloudflare DNS-over-HTTPS, per-hop URL/DNS
validation, four redirects, a 12-second deadline through body consumption, and
streaming limits (3 MB HTML / 256 KB CSS). No visitor credentials are forwarded;
HTML is parsed in an inert template and all report text uses textContent.

Wrangler config includes TOOL_RATE_LIMITER (20 requests per minute per IP at the
Cloudflare location). The bounded in-memory fallback is for environments without
the binding and is not a global limit. Keep Cloudflare's public fetch routing flag.
DNS preflight and the subsequent runtime fetch resolve separately: preflight is
not DNS pinning. This helper depends on Cloudflare's outbound network restrictions;
do not reuse it on a server with private network access without pinned resolution
or an egress proxy that enforces public-only destinations.

URL scans fetch the submitted page and do not execute JavaScript or crawl the site.
Blocked sites can be tested using pasted source. Reports are generated locally;
API responses use no-store and the app does not persist scan history.

## Vocabulary provenance and updates

`schema-vocabulary.json` is a reduced derivative of the official
[Schema.org vocabulary](https://schema.org/version/latest/schemaorg-current-https.jsonld).
It retains type inheritance and property domain/range identifiers, with a retrieval
date and SHA-256 of the downloaded source. The initial snapshot has 933 types and
1,521 properties. Names/relations are not generated by a model.

Attribution: Schema.org sponsors (Google, Yahoo, Microsoft, Yandex) and contributors.
The vocabulary and this reduced derivative are licensed under
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), per
[Schema.org terms](https://schema.org/docs/terms.html). This attribution applies to
the vocabulary data, not an assertion of endorsement of the tool.

Download the current source, then run:

```sh
node scripts/refresh-schema-vocabulary.mjs /path/to/schemaorg-current-https.jsonld
npm run test:inspectors
npm run build
```

Review the vocabulary diff before committing updates. Domain/range findings should
remain warnings. Google requirements change independently; this tool does not
bundle or claim to implement them.

## Verification

`npm run test:inspectors` runs mocked fetch security/compatibility checks and browser
fixtures for parser/detector behavior. Install Playwright Chromium or set
`PLAYWRIGHT_CHANNEL=chrome` to use installed Chrome.

With `npm run dev` running, `npm run test:inspectors:ui` checks both tools at 375px
and 1280px, exports, clearing, mocked URL/theme results, API failures, and real local
API rejection/public fetch. It saves light/dark screenshots under ignored
`scripts/.shots/`. `TEST_BASE_URL` overrides the default localhost:4321.
